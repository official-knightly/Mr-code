<p align="center"><strong>An open-source AI research and development project.</strong></p>

Aegis is a derivative project built from the upstream Qwen codebase. This repository preserves the imported implementation and supporting tools while establishing the Aegis project identity.

## Project status

This repository contains source code, examples, evaluation utilities, recipes, and deployment configurations. It does **not** include pretrained model weights. Importing source code alone does not create or train a new AI model.

## Getting started

1. Review the upstream documentation, license, and notices included here.
2. Install the dependencies listed in the relevant `requirements*.txt` file.
3. Follow the instructions in the relevant recipe or demo directory.
4. Obtain compatible model weights separately, after reviewing their license and usage terms.
